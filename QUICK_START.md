# Быстрый старт - Получение APK без компьютера

## Способ 1: GitHub Actions (Автоматическая сборка) ⭐ РЕКОМЕНДУЕТСЯ

После того как вы запушите код, GitHub автоматически соберет APK:

### Шаги:

1. **Зайдите в ваш GitHub репозиторий** на сайте github.com

2. **Перейдите во вкладку "Actions"** (в верхнем меню)

3. **Выберите workflow "Build APK"** (он запустится автоматически после push)

4. **Когда сборка завершится**, нажмите на завершенную сборку

5. **Скачайте APK**:
   - Прокрутите вниз до секции "Artifacts"
   - Нажмите на "app-debug" - начнется скачивание ZIP архива
   - Разархивируйте ZIP - внутри будет `app-debug.apk`

6. **Перенесите APK на телефон** любым способом:
   - Через USB
   - Отправьте себе в Telegram/WhatsApp
   - Загрузите в Google Drive и скачайте на телефон
   - По email

7. **Установите APK на телефон**:
   - Откройте файл на телефоне
   - Разрешите установку из неизвестных источников (если попросит)
   - Нажмите "Установить"

### Важно:

Перед тем как это сработает, нужно добавить один файл - `gradle/wrapper/gradle-wrapper.jar`.

Есть два варианта:

#### Вариант А: Через Android Studio (если есть доступ к компьютеру)
1. Откройте проект в Android Studio
2. Android Studio автоматически создаст этот файл
3. Закоммитьте и запушьте изменения

#### Вариант Б: Скачать вручную
1. Скачайте файл с https://raw.githubusercontent.com/gradle/gradle/master/gradle/wrapper/gradle-wrapper.jar
2. Положите его в `gradle/wrapper/gradle-wrapper.jar`
3. Закоммитьте и запушьте

## Способ 2: Онлайн сервисы для сборки Android

Можно использовать онлайн IDE с поддержкой Android:

### Gitpod (бесплатно 50 часов/месяц)
1. Откройте ваш репозиторий на gitpod.io:
   ```
   https://gitpod.io/#https://github.com/yonishepelev/anroid-reminder-app
   ```
2. Установите Android SDK в Gitpod
3. Соберите APK командой: `./gradlew assembleDebug`

### Codespaces (GitHub)
1. В вашем репозитории нажмите Code → Codespaces → Create codespace
2. В терминале выполните установку SDK и сборку

## Что дальше?

После установки приложения на телефон:
1. Откройте приложение "Напоминания"
2. Нажмите "+" чтобы создать напоминание
3. Настройте название, время и тип повторения
4. Сохраните
5. В указанное время придет уведомление!

## Разрешения

При первом запуске приложение запросит разрешение на отправку уведомлений - обязательно разрешите, иначе напоминания не будут работать.
